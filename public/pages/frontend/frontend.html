HTML

HTML stands for HyperText Markup Language.

HTML is used to structure the content on a website. This happens through different HTML elements.

Some examples of HTML elements are:

  • <h1> to <h6> - headings
  • <p> - paragraphs
  • <a> - links
  • <div> - container for content
  • <img> - images
  • <script> - JavaScript
  • <link> - links to external resources such as CSS files
  • <meta> - metadata about the document

HTML Document Structure

An HTML document consists of different parts, including head and body.

The head contains information about the document, such as the title, metadata and links to CSS files.

The body contains the visible content of the webpage, such as headings, paragraphs, images and links.

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My documentation website</title>
</head>
<body>
    <h1>Welcome to my documentation website</h1>
</body>
</html>

Script Tag

The script tag is used to include JavaScript in an HTML document.

JavaScript can be written directly inside the script tag or loaded from an external JavaScript file using the src attribute.

<script>
    console.log('Hello World');
</script>
<script src="/frontpage/frontpage.js"></script>

A script tag can be placed in the head or the body of an HTML document. The defer attribute can be used with external classic scripts to ensure that the HTML is parsed before the JavaScript runs.

<head>
    <script src="app.js" defer></script> 
</head>

DOM and JavaScript

DOM stands for Document Object Model.

The DOM represents the HTML document as objects that JavaScript can access and change.

JavaScript can be used to create a new HTML elements, find existing elements and change their content.

Creating HTML Elements with JavaScript

const paragraph = document.createElement('p');
paragraph.textContent = 'Programming is cool';
document.body.appendChild(paragraph);

In this example, createElement() creates a new paragraph element.

textContent adds text to the paragraph.

appendChild() adds the paragraph to the body of the HTML document.

Accessing and Updating HTML Elements

JavaScript can also find an existing HTML element and change its content.

The client-side (HTML and JavaScript):

<h3 id="counter"></h3>

<script>
    fetch('/api/counter')
        .then((response) => response.json())
        .then((result) => {
            const counterH3 = document.getElementById('counter');
            counterH3.textContent = result.data;
        });
</script>

getElementById() finds the HTML element with the id "counter".

textContent changes the text inside the element to the value of result.data.

The value comes from the response to the fetch request.

The server-side (Express):

let counter = 0;

app.get('/api/counter', (req, res) => {
    res.send({ data: ++counter});
});

The server increases the counter by one for each request and returns the updated value as JSON.

CSS

CSS stands for Cascading Style Sheets.

CSS is used to style HTML elements, such as changing colors, fonts, font sizes, padding and border-radius.

Inline CSS

Inline CSS is written directly inside an HTML element using the style attribute.

<body style="background-color: red;">

In this example, the background-color property sets the background color of the body to red.

Internal CSS

Internal CSS is written inside a style tag in the HTML document, usually in the head.

<head>
    <style>
        h1 {
            color: darkred;
        }
    </style>
</head>

In this example, the CSS selector h1 selects all h1 elements, and the color property changes their text color to dark red.

External CSS

External CSS is written in a separate CSS file and linked to the HTML document using a link tag in the head.

<link rel="stylesheet" href="/frontpage/frontpage.css">

The href attribute specifies the path to the CSS file, and rel="stylesheet" tells the browser that the linked file is a stylesheet.

CSS Selectors

CSS selectors are used to select the HTML elements that should be styled.

Elements can be selected by their tag name, class or id.

/* Element selector */
h1 {
    color: darkred;
}

/* Class selector */
.container {
    padding: 20px;
}

/* ID selector */
#counter {
    font-size: 24px;
}

The h1 selector selects all h1 elements.

The .container selector selects elements with the class "container".

The #counter selector selects the element with the id "counter".

Semantic HTML

Semantic HTML means using HTML elements that describe the meaning and purpose of the content.

Examples of semantic HTML elements are:

  • <header> - introductory content, such as a website header
  • <nav> - navigation links
  • <main> - the main content of the webpage
  • <section> - a thematic section of content, usually with a heading
  • <footer> - footer information

Semantic HTML Structure

Semantic HTML elements can be used to organize a webpage into different parts.

<header>
    <h1>My Website</h1>
</header>

<nav>
    <a href="/">Home</a>
</nav>

<main>
    <section>
        <h2>About</h2>
        <p>Information about the website.</p>
    </section>
</main>

<footer>
    <p>My Website</p>
</footer>

The main element contains the primary content of the webpage, while section can be used to divide the content into thematic sections.

Static files

Static files are files that the server can send to the client without generating their content dynamically. Examples include HTML, CSS, JavaScript files and images.

Express Static

Express can serve static files from a directory using express.static().

app.use(express.static('public'));

In this example, Express makes the files inside the public directory available to the client.

Static File Paths

When using express.static('public'), the public directory becomes the root directory for static files.

For example, if the CSS file is located at public/frontpage/frontpage.css, it can be linked in HTML like this:

<link rel="stylesheet" href="/frontpage/frontpage.css">

The public directory is not included in the URL because Express serves files relative to that directory.

Frontend structure

A frontend project can be organized into folders to separate HTML, CSS, JavaScript and images.

Organizing files makes the project easier to navigate and maintain.

Folder Structure

This is an example of a project where frontend files are organized into pages, components and assets.

project/
├── public/
│   ├── assets/
│   │   ├── css/
│   │   │   └──index.css
│   │   ├── images/
│   │   │   └── plant.png
│   │   └── js/
│   │       ├── escapeHTML.js
│   │       └── footer.js
│   ├── components/
│   │   ├── footer/
│   │   │   └── footer.html
│   │   └── header/
│   │       └── header.html
│   └── pages/
│       ├── about
│       │   └── about.html  
│       └── frontpage
│           ├── frontpage.css
│           ├── frontpage.html
│           └── frontpage.js
├── templatingEngine/
│   ├── pages.js
│   └── templatingEngine.js
├── util/
│    └──fetchPlants.js
├── app.js
├── nodemon.json
├── package-lock.json
└── package.json

The assets directory contains CSS, JavaScript and images.

The components directory contains reusable parts of the website, such as the header and footer.

The pages directory contains the content for individual pages.

Client-side JavaScript

Client-side JavaScript runs in the browser and can be used to make webpages interactive.

JavaScript Modules in the Browser

JavaScript modules allow code to be split into separate files using import and export.

The type="module" attribute tells the browser to treat the JavaScript file as an ES module.

<script type="module" src="/frontpage/frontpage.js"></script>

Module scripts are deferred by default, meaning they run after the HTML document has been parsed.

Client-Side Redirects

Client-side redirects can be used to navigate the browser to another page using JavaScript.

setTimeout(() => {
    // window.location.href = "/";
    // location.href = "/";
    // location.replace('/');
}, 3000);

setTimeout() runs a function after a specified delay. In this example, the delay is 3000 milliseconds (3 seconds).

window.location.href and location.href can be used to navigate to another URL.

location.replace() also navigates to another URL, but replaces the current page in the browser history.

The redirect statements are commented out in this example. To perform a redirect, one of them must be uncommented.

HTML Redirect

A redirect can also be created using a meta refresh tag in HTML.

<meta http-equiv="refresh" content="3;/">

In this example, the browser redirects to the front page after 3 seconds.
