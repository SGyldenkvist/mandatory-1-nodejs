What is a REST API?

REST stands for Representational State Transfer. It is an architectural style for designing APIs.

An API (Application Programming Interface) allows applications to communicate with each other.

REST APIs use HTTP methods to perform operations on resources.

HTTP Methods and CRUD

HTTP methods describe which operation a client wants to perform on a resource.

CRUD stands for Create, Read, Update and Delete. These operations can be mapped to HTTP methods.

HTTP Methods

  • GET: Retrieve resources (Read).
  • POST: Create a new resource (Create).
  • PUT: Replace an existing resource (Update).
  • PATCH: Partially update an existing resource (Update).
  • DELETE: Remove a resource (Delete).

  • Ordering: The HTTP methods are listed in a consistent order, making the API easier to read.

GET Requests

The GET method is used to retrieve resources from a server.

GET All Animals

The /animals endpoint returns all animals stored in the array.

app.get('/animals', (req, res) => {
    res.send({ data: animals });
});

app.get() defines a route that handles GET requests. The response contains the animals array inside a data property.

GET Animal by ID

The /animals/:id endpoint retrieves a specific animal using a route parameter.

app.get("/animals/:id", (req, res) => {
    const providedId = Number(req.params.id);
    const foundAnimal = animals.find((animal) => animal.id === providedId);

    if (!foundAnimal) {
        return res.status(404).send({
            errorMessage: `No animal found by id ${providedId}`
        });
    }

    res.send({ data: foundAnimal });
});

req.params.id retrieves the id from the url. Number() converts it from a string to a number, and find() searches the array for a matching animal.

If no animal is found, the server returns HTTP status code 404 (Not Found).

POST Requests

The POST method is used to create a new resource on the server.

Creating a New Animal

In the Animals API, a POST request to /animals adds a new animal to the array.

let nextId = 3;

app.post("/animals", (req, res) => {
    const providedAnimal = req.body;

    providedAnimal.id = nextId++;

    animals.push(providedAnimal);

    res.status(201).send({ data: providedAnimal });
});

req.body contains the data sent by the client. The server assigns a unique id using nextId++, adds the animal to the array using push(), and returns the created animal.

Parsing JSON Request Bodies

Express needs JSON middleware to read JSON data from incoming requests.

app.use(express.json());

This middleware parses incoming JSON request bodies and makes the data available through req.body.

PUT Requests

The PUT method is used to replace an existing resource.

PUT Example

app.put('/animals/:id', (req, res) => {
    const providedId = Number(req.params.id);

    const foundIndex = animals.findIndex(
        (animal) => animal.id === providedId
    );

    if (foundIndex === -1) {
        return res.status(404).send({
            data: `No animal found by id ${providedId}`
        });
    }

    const updatedAnimal = req.body;
    updatedAnimal.id = providedId;

    animals[foundIndex] = updatedAnimal;

    res.send({ data: updatedAnimal });
});

req.params.id gets the animal's id from the url, and findIndex() finds its position in the array. If the animal is not found, the server returns status code 404. Otherwise, the existing animal is replaced with the data from req.body, while keeping the original id.

PATCH Requests

The PATCH method is used to partially update an existing resource.

PUT vs. PATCH

PUT replaces an existing resource, while PATCH updates selected properties without replacing the entire resource.

In practice, PATCH is often used when only specific properties need to be updated, instead of replacing the entire resource with PUT.

Updating an Animal

In the Animals API, PATCH /animals/:id updates an animal using its id.

app.patch("/animals/:id", (req, res) => {
    const providedId = Number(req.params.id);
    const foundAnimalIndex = animals.findIndex((animal) => animal.id === providedId);

    if (foundAnimalIndex === -1) {
        return res.status(404).send({
            errorMessage: `No animal found by id ${providedId}`
        });
    }

    const providedAnimal = req.body;
    const foundAnimal = animals[foundAnimalIndex];

    const animalToCreate = { ...foundAnimal, ...providedAnimal, id: providedId };

    animals[foundAnimalIndex] = animalToCreate;

    res.send({ data: animalToCreate });
});

Although the variable is named animalToCreate, the PATCH request updates an existing animal rather than creating a new one. PATCH changes selected properties while preserving the others, unlike PUT, which replaces the resource.

findIndex() finds the position of the animal in the array. If the animal does not exist, the server returns status code 404.

The spread operator (...) combines the existing animal with the new values from req.body. Properties provided in the request overwrite existing properties, while other properties are preserved.

The id is set to providedId to prevent the request body from changing the animal's id.

DELETE Requests

The DELETE method is used to remove a resource from the server.

Deleting an Animal

In the Animals API, DELETE /animals/:id removes an animal using its id.

app.delete("/animals/:id", (req, res) => {
    const providedId = Number(req.params.id);
    const foundAnimalIndex = animals.findIndex((animal) => animal.id === providedId);

    if (foundAnimalIndex === -1) {
        return res.status(404).send({
            errorMessage: `No animal found by id ${providedId}`
        });
    }

    animals.splice(foundAnimalIndex, 1);

    res.status(204).send();
});

findIndex() searches for the animal's position in the array. If the animal does not exist, the server returns HTTP status code 404 (Not Found).

splice(foundAnimalIndex, 1) removes one element from the array at the specified index.

If the animal is deleted successfully, the server returns HTTP status code 204 (No Content), meaning the request succeeded without returning a response body.

HTTP Status Codes

HTTP status codes indicate the result of a request sent from a client to a server.

  • 2xx – Success: The request was successful.
  • 3xx – Redirection: The client is redirected to another location.
  • 4xx – Client Error: The request could not be completed because of a client-side issue.
  • 5xx – Server Error: The server encountered an error.

Status Codes in the Animals API

  • 200 OK: A successful GET, PUT or PATCH request.
  • 201 Created: A new animal was succesfully created using POST.
  • 204 No Content: An animal was successfully deleted without returning a response body.
  • 404 Not Found: No animal was found with the provided id.

Express uses res.status() to set the HTTP status code of a response.

res.status(404).send({
    errorMessage: `No animal found by id ${providedId}`
});
