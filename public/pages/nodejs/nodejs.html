Node.js

Documentation of Node.js concepts, including npm, dependencies, modules and environment variables

What is Node.js?

Node.js is a runtime environment that allows JavaScript to execute outside the browser. This way, JavaScript can be used for both frontend and backend development.

Running JavaScript with Node.js

JavaScript files can be executed with Node.js through the terminal using the node command and the filename.

node app.js

Node.js also provides a REPL (Read-Eval-Print Loop), which allows JavaScript code to be executed interactively in the terminal.

To start the REPL:

node

Example:

> 2 + 3
5

To exit the REPL, type .exit.

npm and dependencies

npm (Node package manager) is used to install and manage packages in a Node.js project. The packages are the project's dependencies.

To initialize a new Node.js project:

npm init

This command guides you through creating a package.json file, where you can configure project information such as its name, version and description.

To initialize a project using default values:

npm init -y

To install a package like Express (a web framework for Node.js):

npm install express

The installed package is added to the project's dependencies in package.json.

To install the dependencies listed in an existing package.json:

npm install

package.json, package-lock.json and node_modules

package.json contains information about the project, including its dependencies and scripts.

Example from this documentation project's package.json:

{
    "name": "mandatory-1",
    "version": "1.0.0",
    "type": "module",
    "dependencies": {
        "express": "^5.2.1"
    }
}

package-lock.json records the exact dependency versions installed.

The node_modules directory contains the installed packages.

npm scripts and nodemon

npm scripts are commands defined in the scripts section of package.json. They make it easier to run common tasks.

Example from the Planter project:

"scripts": {
    "start": "cross-env PORT=80 node app.js",
    "start-dev": "cross-env PORT=9090 nodemon app.js"
}

npm start runs the start script and starts the application on port 80.

npm run start-dev runs the development script on port 9090.

Nodemon is a development tool that automatically restarts the Node.js application when watched files change.

cross-env allows environment variables to be set across different operating systems.

CommonJS vs. ES Modules

Node.js supports different module systems for importing and exporting code between files.

CommonJS uses require() to import modules and module.exports to export them.

const express = require('express');

ES Modules use import and export.

import express from 'express';

Import and Export

Modules allow code to be organized into separate files. Import and export make it possible to reuse code between these files.

CommonJS example:

In CommonJS, require() is used to import modules, and module.exports is used to export values.

fruitOrchard.json:

{
    "fruits": ["🥭", "🥭", "🥝", "🍉", "🍒", "🍇"]
}

CommonJS fruit module:

const fruitOrchard = require('./fruitOrchard.json');

module.exports = {
    fruits: fruitOrchard.fruits,
    slogan: "Yummy yummy in my tummy"
};

ES Modules example:

In ES Modules, export default makes a value available for import in another file.

fruitsUtilESModule.js:

const fruitOrchard = 'The fruits have been harvested';

export default {
    fruits: fruitOrchard,
    slogan: "They are colorful, what is there not to like"
};

app.js:

import fruitPackage from './util/fruitsUtilESModule.js';

console.log(fruitPackage.slogan, fruitPackage.fruits);

ES Modules support both named exports and default exports. Named exports are imported using curly braces {}, while default exports are imported without them.

Example of a named export:

// templatingEngine.js
export function readPage(path) {
    return fs.readFileSync(path, 'utf-8');
}

// pages.js
import { readPage } from './templatingEngine.js';

ES modules can be enabled in a Node.js project by setting "type": "module" in package.json.

Environment variables

Environment variables allow configuration values to be provided outside the source code. In Node.js they can be accessed through process.env.

const PORT = process.env.PORT ?? 8080;

This uses the PORT environment variable if it is defined. Otherwise, the default value is 8080.

The ?? operator is called the nullish coalescing operator. It returns the value on the right if the value on the left is null or undefined.

cross-env can be used in npm scripts to set environment variables. For example, cross-env PORT=9090 sets the PORT environment variable to 9090, which can then be accessed through process.env.PORT in the application.

Node.js Built-in modules (fs and path)

Node.js includes built-in modules such as fs for working with files and path for working with file paths.

import fs from 'fs';
const content = fs.readFileSync("example.txt", "utf-8");

fs.readFileSync() reads the contents of a file synchronously. The "utf-8" encoding returns the content as a string. Synchronous means that the program waits until the file has been read before continuing.

The path module can be used to work with file paths. The path.resolve() method creates an absolute path.

import path from 'path';

const filePath = path.resolve('public/index.html');
