What is Express?

Express is a web framework for Node.js used to build web servers and web applications. It provides functionality for handling HTTP requests and responses, defining routes, and using middleware.

Node.js can create a web server using its built-in HTTP module, but Express simplifies common tasks by providing methods such as app.get(), res.send() and app.listen().

Setting Up an Express Server

To set up an Express server, first import the Express module.

Then call express() to create an Express application and store it in the app variable.

Then app.listen(8080) starts the server on port 8080. The callback function runs when the server has started and prints a message in the terminal.

import express from 'express';

const app = express();

app.listen(8080, () => {
    console.log('Server is running on port', 8080);
});

Routing

Routing determines how the server responds to requests sent to specific endpoints. In Express, routes are defined using methods such as app.get() and app.post(). 

app.get('/blablabla', (req, res) => {
    res.send({ data: "They talk a lot but nothing is said" });
});

For more examples of HTTP methods and endpoints, see the REST API documentation.

Route Parameters and Query Parameters

Route Parameters

Route parameters are dynamic values in a url path. In Express, they are defined using a colon (:) and can be accessed through req.params.

Route parameters are received as strings, even when they contain numbers.

app.get('/beers/:beerType/:amount', (req, res) => {
    res.send({
        data: `You ordered ${req.params.amount} of ${req.params.beerType}`
    });
});

For example, a GET request to /beers/IPA/3 gives beerType the value "IPA" and amount the value "3".

Query Parameters

Query parameters are used to send additional information through a url. They appear after a question mark (?) and are written as key-value pairs. Multiple query parameters are separated by an ampersand (&). 

app.get('/bars/forgottenItems', (req, res) => {
    res.send({ data: req.query });
});

For example, /bars/forgottenItems?item=phone&color=black sends two query parameters: item and color. In Express, these values can be accessed through req.query.

Sending Responses

Express uses the response object (res) to send a response back to the client.

res.send()

res.send() sends a response to the client. The response can contain text, HTML or an object.

app.get('/blablabla', (req, res) => {
    res.send({ data: "They talk a lot but nothing is said" });
});

res.sendFile()

res.sendFile() sends an HTML file or another file to the client.

import path from 'path';

app.get('/', (req, res) => {
    res.sendFile(path.resolve('public/frontpage/index.html'));
});

Middleware and Static Files

Middleware

Middleware functions run during the request-response cycle. They can process requests, send responses or pass control to the next middleware function.

app.use(express.json());

express.json() is built-in middleware that parses incoming JSON request bodies and makes the parsed data available through req.body.

Static Files

Static files are files such as CSS, client-side JavaScript and images that the server sends to the browser.

Express provides built-in middleware called express.static() to make files in a specified directory publicly accessible.

app.use(express.static('public'));

In this example, Express serves static files from the public directory. For example, a file located at public/frontpage/frontpage.css can be accessed through /frontpage/frontpage.css.

Redirects

A redirect tells the client to make a new request to a different url. In Express, redirects can be created using res.redirect().

app.get('/chatterroom', (req, res) => {
    res.redirect('/blablabla');
});

In this example, a request to /chatterroom redirects the client to /blablabla. By default, res.redirect() sends the HTTP status code 302 (Found), indicating a temporary redirect.
