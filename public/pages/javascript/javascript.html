Data Types

JavaScript has eight data types: String, Number, Boolean, BigInt, Undefined, Null, Symbol and Object.

const name = "Maxi";                  // String
const age = 9;                        // Number
const isHappy = true;                 // Boolean
const bigNumber = 123n;               // BigInt
let favoriteToy;                      // Undefined
const missingValue = null;            // Null
const id = Symbol("id");              // Symbol
const dog = { name: "Maxi", age: 9 }; // Object

Arrays are also objects in JavaScript.

Variables

Variables are used to store values in JavaScript. They can be declared using const, let or var.

Use const whenever possible, otherwise let.

The use of var should generally be avoided because it is not block-scoped.

const

A variable declared with const cannot be reassigned. However, objects and arrays declared with const can still be modified.

const person = {
    name: "Amin"
};

person.age = 123;
const things = ["mouse"];

things.push("car");

The person object now has both name and age properties, and the things array contains "mouse" and "car".

let

Variables declared with let can be reassigned. They are block-scoped, meaning they are only accessible within the block where they are declared.

let age = 9;
age = 10;

var

Variables declared with var can also be reassigned, but unlike let and const, var is not block-scoped. This can lead to unexpected behavior.

{
    var someValue = 123;
    {
        var someValue = 456;
    }
    console.log(someValue); 
}

The output is: 456

The inner declaration changes the same variable because var does not create a new block-scoped variable.

Prefix and Postfix Increment

The increment operator (++) increases a variable by 1. The difference between prefix and postfix is when the value is returned.

let value = 5;

// Postfix
console.log(value++); // 5
console.log(value);   // 6

// Prefix
console.log(++value); // 7
console.log(value);   // 7

Postfix (value++) returns the original value before incrementing it. Prefix (++value) increments the variable first and then returns the new value.

Scope

Scope determines where a variable can be accessed in the code.

Variables declared with let and const are block-scoped, while var is function-scoped or global-scoped, depending on where it is declared.

Block Scope

A block is defined by curly braces {}. Variables declared with let inside a block are not accessible outside that block.

{
    let someOtherValue = true;

    {
        let someOtherValue = false;
    }

    console.log(someOtherValue); 
}

The output is true.

The inner block has its own variable. It does not change the variable in the outer block.

Scope in Loops

Using var and let in a loop can produce different results when a callback function is executed later.

Example using var:

for (var i = 0; i <= 5; i++) {
    setTimeout(() => {
        console.log(i);
    }, 1000);
}

Output after one second: 6, 6, 6, 6, 6, 6.

Example using let:

for (let i = 0; i <= 5; i++) {
    setTimeout(() => {
        console.log(i);
    }, 1000);
}

Output after approximately one second: 0, 1, 2, 3, 4, 5.

With var, all callbacks share the same variable, which has reached 6 when they execute.

With let, each loop iteration gets its own binding of i.

Type Coercion and Equality

Type coercion happens when JavaScript automatically converts a value from one data type to another.

console.log("5" == 5);

The output is "true".

console.log("5" === 5);

The output is: "false".

The == operator allows type coercion, while === compares both value and data type without converting them.

Always using strict equality operators (=== and !==) to avoid unexpected results.

Strings and Template Literals

Strings are used to represent text in JavaScript. They can be written using single quotes, double quotes or backticks.

const greetingOne = "Hej med dig, '''''ven'";
const greetingTwo = 'Hej med dig, """"""""""ven"';

Template Literals

Template literals use backticks (`) and allow variables and expressions to be inserted using ${}.

const person = { name: "Amin" };

const greetingThree = `Hej, med 'dig', "${person.name}"`;

console.log(greetingThree);

Template literals also support strings that span multiple lines without using special newline characters.

Objects and Arrays

Objects

Objects store data as key-value pairs. Properties can be accessed and modified using dot notation.

const person = {
    name: "Amin"
};

person.age = 123;

console.log(person);

Even though person is declared with const, its properties can still be modified.

Arrays

Arrays store multiple values in an ordered collection. Array elements can be accessed using their index, starting at 0.

const things = ["mouse"];

things.push("car");

console.log(things[0], things[1]);

The push() method adds an element to the end of an array. The example prints "mouse" and "car".

Functions

Functions are reusable blocks of code that can receive parameters and return values.

Function Declaration

A function declaration uses the function keyword. Function declarations are hoisted, meaning they can be called before they appear in the code.

getRandomInt(5, 10);

function getRandomInt(min, max) {
    return Math.floor(Math.random() * (max - min + 1) + min);
}

Function Expression

A function can also be assigned to a variable.

const getRandomIntAnonymousFunction = function(min, max) {
    return Math.floor(Math.random() * (max - min + 1) + min);
};

Arrow Function

Arrow functions provide a shorter syntax for writing functions.

const getRandomIntArrowFunction = (min, max) => {
    return Math.floor(Math.random() * (max - min + 1) + min);
};

Callbacks and higher-order Functions

In JavaScript, functions can be passed as arguments to other functions. A function that receives another function as an argument is called a higher-order function.

A callback is a function passed to another function to be executed by it.

function genericActionPerformer(name, action) {
    return action(name);
}

function playingGuitarAction(name) {
    return `${name} likes to play guitar`;
}

console.log(
    genericActionPerformer("Elias", playingGuitarAction)
);

The genericActionPerformer function receives a name and a callback function. It calls the callback with the provided name.

Output: Elias likes to play guitar

Loops and Array Methods

Loops are used to repeat operations. Use built-in array methods instead of traditional for loops whenever possible.

forEach()

The forEach() method executes a callback function for each element in an array. It does not create a new array.

const numbers = [1, 2, 3, 4, 5];

numbers.forEach(number => {
    console.log(number);
});

map()

The map() method transforms each element and returns a new array with the same number of elements.

const numbers = [1, 2, 3, 4, 5];

const doubledNumbers = numbers.map(number => number * 2);

console.log(doubledNumbers);

The output is: [2, 4, 6, 8, 10]

filter()

The filter() method returns a new array containing only the elements that satisfy a condition.

const countries = [
    { name: "Lesotho", gdp: 530 },
    { name: "Papua New Guinea", gdp: 1025 },
    { name: "Saint Vincent and the Grenadines", gdp: 1200 }
];

const richCountries = countries.filter(
    country => country.gdp > 1000
);

The result contains Papua New Guinea and Saint Vincent and the Grenadines.

Loops · Recommended Practices and common pitfalls

JavaScript supports traditional for loops, for...in and for...of. However use built-in array methods whenever possible.

Traditional Loops

A traditional for loop requires manually managing an index.

const numbers = [6, 7, 8, 9];

for (let i = 0; i < numbers.length; i++) {
    console.log(numbers[i]);
}

For simple array iteration, forEach() is often clearer:

numbers.forEach(number => console.log(number));

for...in and for...of

for...in iterates over property keys, while for...of iterates over values.

let list = [4, 5, 6];

for (let i in list) {
    console.log(i); 
}

The output is: "0", "1", "2" (strings)


for (let i of list) {
    console.log(i); 
}

The output is: 4, 5, 6 (numbers)

Avoiding Side Effects

Changing the original array during iteration can cause unintended side effects. Methods such as map() can create a new array instead.

const numbers = [6, 7, 8, 9];

const doubledNumbers = numbers.map(number => number * 2);

doubledNumbers: [12, 14, 16, 18]

numbers remains unchanged

find()

The find() method returns the first element in an array that satisfies a condition. If no element matches, it returns undefined.

const numbers = [1, 2, 3, 4, 5];

const foundNumber = numbers.find(number => number > 3);

console.log(foundNumber); // 4

findIndex()

The findIndex() method returns the index of the first element that satisfies a condition. If no element matches, it returns -1.

const numbers = [1, 2, 3, 4, 5];

const foundIndex = numbers.findIndex(number => number > 3);

console.log(foundIndex); // 3

indexOf()

The indexOf() method returns the index of a specified value in an array. If the value is not found, it returns -1.

const numbers = [1, 2, 3, 4, 5];

console.log(numbers.indexOf(3)); // 2
console.log(numbers.indexOf(9)); // -1

reduce()

The reduce() method processes the elements of an array and combines them into a single result.

const numbers = [1, 2, 3, 4, 5];

const sum = numbers.reduce((accumulator, number) => {
    return accumulator + number;
}, 0);

console.log(sum); // 15

The reduce() method combines all numbers into a single result. The accumulator starts at 0 and stores the running total as each number is added.

Date and Time

JavaScript has a built-in Date object that is used to work with dates and time.

Creating a Date Object

const currentDate = new Date();

console.log(currentDate);

new Date() creates a Date object representing the current date and time.

Date()

console.log(Date());

Calling Date() without new returns a string representing the current date and time.

Date.now()

Date.now() returns the number of milliseconds since January 1, 1970 (Unix Epoch Time).

console.log(Date.now());

Unlike new Date(), Date.now() returns a number rather than a Date object.

Date Methods

JavaScript provides methods for retrieving individual parts of a date.

const currentDate = new Date();

console.log(currentDate.getFullYear());
console.log(currentDate.getMonth());
console.log(currentDate.getDate());
console.log(currentDate.getDay());
console.log(currentDate.getHours());
console.log(currentDate.getMinutes());
console.log(currentDate.getSeconds());

getFullYear() returns the year, while getMonth() returns the month as a number from 0 to 11.

getDate() returns the day of the month, while getDay() returns the day of the week from 0 (Sunday) to 6 (Saturday).

getHours(), getMinutes() and getSeconds() return the individual time components.

Formatting Dates

JavaScript provides methods for converting Date objects into different string formats.

const currentDate = new Date();

console.log(currentDate.toString());
console.log(currentDate.toDateString());
console.log(currentDate.toISOString());
console.log(currentDate.toLocaleString("da-DK"));

toString() returns a readable date and time including timezone information.

toDateString() returns the date without the time.

toISOString() returns the date and time in ISO 8601 format using UTC.

toLocaleString("da-DK") formats the date and time according to Danish conventions.

Finding the Current Month

The current month can be retrieved in different ways using JavaScript.

Using getMonth()

The month number is used as an index to find the corresponding month name in an array (0-11).

const months = [
    'January', 'February', 'March', 'April', 'May', 'June',
    'July', 'August', 'September', 'October', 'November', 'December'
];

const currentMonth = months[new Date().getMonth()];

console.log(currentMonth);

Using toLocaleDateString()

toLocaleDateString() can return the month name directly when given formatting options.

const currentMonth = new Date().toLocaleDateString(
    'en-GB',
    { month: 'long' }
);

console.log(currentMonth);

Both approaches return the name of the current month.

Finding the Current Day

The current day of the week can be retrieved using getDay() or toLocaleDateString().

Using getDay()

getDay() returns a number between 0 (Sunday) and 6 (Saturday). This number can be used as an index in an array.

const days = [
    "Sunday", "Monday", "Tuesday", "Wednesday",
    "Thursday", "Friday", "Saturday"
];

const currentDay = days[new Date().getDay()];

console.log(currentDay);

Using toLocaleDateString()

toLocaleDateString() can return the weekday name directly.

const currentDay = new Date().toLocaleDateString(
    'en-GB',
    { weekday: 'long' }
);

console.log(currentDay);

Both approaches return the name of the current weekday.
